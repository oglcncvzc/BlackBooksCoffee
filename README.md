# BLACK BOOKS & COFFEE • QR Menü & Web Uygulaması

Kadıköy Moda'nın butik sahaf ve kahve noktası **Black Books & Coffee** için geliştirilmiş, siyah-beyaz & sıcak ahşap temalı, ultra hızlı, mobil uyumlu yeni nesil QR Menü web uygulaması.

---

## ☕ Menü & Özellikler

- **Sıcak Kahveler**: Espresso (Single/Double), Ristretto, Lungo, Americano, Caffè Crema, Cappuccino, Caffè Latte, Latte Macchiato, Flat White, Türk Kahvesi
- **Soğuk Kahveler**: Iced Americano, Iced Latte, Espresso Tonic
- **Sıcak & Soğuk Çaylar**: Demleme Siyah Çay (Küçük/Büyük), Yeşil Çay, Şeftali & Çarkıfelek, Çilek & Portakal
- **Soğuk İçecekler**: Soda (Maden Suyu), Doğal Kaynak Suyu
- **Siparişini Göster (Büyük Ekran Modu)**: Masada seçilen içecekleri loş ışıkta bile uzaktan okunabilir dev fontlarla tek ekranda gösterme.
- **Wi-Fi Hızlı Kopyalama**: Mekan misafir ağı şifresini tek tıkla kopyalama modalı.
- **NadirKitap Sahaf Vitrini**: Nadir kitap seçkisi online dükkan yönlendirmesi.
- **Sosyal & Harita Bağlantıları**: Instagram (`@blackbooksmoda`), NadirKitap ve Yandex Haritalar.

---

## 🛠️ Teknolojiler

- **Framework**: Next.js 14 (App Router) + React 18 + TypeScript
- **İkonlar**: Lucide React
- **Stil**: Pure CSS Design System & Variables (Dark Espresso, Warm Walnut, Golden Glow)

---

## 🚀 Kurulum & Çalıştırma

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Prodüksiyon derlemesi oluştur
npm run build
```
